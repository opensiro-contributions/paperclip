## Central accepted baseline

> **`S1=A · S2=A · S3=A(P) · S3*=A · S4=— · S5=P`**  
> [Accepted Index Paperclip assessment](https://github.com/opensiro/vsm-harness-index/blob/975a58814b767cfca414c152480f787bfe80944b/assessments/pa/paperclip.md), reviewed **2026-11-17** at original `7f986789…`, Profile 0.2.4 / Skills 0.3.8.

The vector is the **original evidence baseline**, **not** the proposed after-state. Accepted `S3=A(P)` is already an autonomous current-management mode with a separate legitimate parent mode; **the independent developer-composable S3 feature is optional and is not an `A(P) → C` regrade**. Accepted `S4=—` is the primary P0 candidate for a future `C` witness, not a proven current deficiency.

**Functional boundary:** S2 coordinates and reduces interference; **S3** regulates the company's *current* resources, commitments and control decisions; **S4** evaluates the *outside environment and possible futures*, develops adaptation choices and returns them into the S3 operating capability; S5 retains identity and ultimate policy. An event notification or queue alone establishes neither S3 nor S4.
